# Mortal スクショ何切る

Mortal（[mjai.ekyu.moe](https://mjai.ekyu.moe/)）の牌譜検討画面の**スクリーンショット**を取り込むと、
AIの推奨（緑の縦棒）と実戦の打牌（赤枠）を消した画像で「何切る」を出題するスマホ向け Web アプリ。
「何切るクイズ」（C:\麻雀、検討URLから取り込むもの）とは別アプリ。

- 画像の解析は**すべて端末内（Canvas）で完結**。通信も API 利用料も不要
- 取り込み時に、手牌の各牌の位置／緑棒の高さ／赤枠を色から検出し、
  - 問題画像：緑棒を背景色で塗りつぶし、赤枠は隣の牌の縁をコピーして消す
  - 答え画像：元のまま（緑棒・赤枠つき）
- 出題は問題画像の下に手牌を大きく表示し、牌をタップ →「決定」で自動採点
  - 正解＝いちばん高い緑棒の牌。同じ絵柄の牌や同じ高さの棒の牌はどれを選んでも正解
  - 「答えを見る（採点しない）」で自己採点もできる
- 自己採点結果は「正解／不正解／要復習」として端末内（IndexedDB + localStorage）に蓄積し、
  「不正解だけ」「要復習だけ」「未出題だけ」「正解済みだけ」「おまかせ」や、取り込んだ回ごとに出題できる
- 緑棒が見つからない画像でも、取り込み画面で正解の牌をタップすれば手動で登録できる
- 設定タブからバックアップの書き出し／読み込み（画像込み）ができる

静的ファイルのみ。GitHub Pages で動作します。

## 使い方

1. Mortal の検討画面で、画面下部の手牌と緑の棒が見える状態でスクリーンショットを撮る
2. アプリの「取り込み」タブで画像を選ぶ（複数可。PC ならドロップ／ペーストも可）
3. 読み取り結果（Mortalの推奨＝緑枠の牌）を確認して「保存」
4. 「クイズ」タブでリストを選んで出題

## 解析の仕組み（index.html の analyzeImage）

| 対象 | 検出方法 |
| --- | --- |
| 盤面 | 緑青（teal）の画素が行の過半を占める範囲 |
| 手牌の帯 | 盤面内でいちばん白い画素が多い行を中心に上下へ広げる |
| 牌の区切り | 帯の中で明るい画素がひとつも無い列（絵柄の列には必ず白がある）。区切りの間隔の中央値から牌のピッチを求める |
| ツモ牌 | 手牌の右にある、牌1枚分の幅のまとまり |
| 緑棒 | 手牌のすぐ上で、鮮やかな緑の縦長の塊。高い順に候補とする |
| 赤枠 | 牌の上端・下端の行が赤い牌。厚みを測って隣の牌の縁で上書きする |
| 同じ牌 | 各牌の内側を 6×8 に縮小して比較。差が小さければ同じ絵柄とみなす |

スクリーンショットの解像度には依存しません（相対値で判定）。
Mortal のビューアの配色（濃い緑青の背景・白い牌・緑の棒・赤い枠）が前提です。
